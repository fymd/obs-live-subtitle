# OBS 实时字幕工具 — 下一迭代需求（v0.3）

## Problem

当前 v2 已可用，但仍有常见痛点：
1. Whisper 偶尔输出繁体或固定幻听词（「谢谢观看」等）
2. 专有名词（游戏名、主播名）识别不准
3. 字幕样式只能改代码，不方便直播时临时调整

## Goals

- 减少幻听与繁体干扰
- 提升专有名词识别准确率
- 支持网页端实时调整字幕样式（字号、颜色、位置、透明度）

## Non-goals

- 不做实时翻译（留到下一迭代）
- 不做 obs-websocket / 原生插件
- 不做打包 exe（先把功能打磨好）

## User Stories

1. **As a** 主播，**I want** 自动把繁体转成简体并过滤常见幻听词，**so that** 字幕干净可读。
2. **As a** 主播，**I want** 在配置里写提示词/热词，**so that** 游戏名和常用词识别更准。
3. **As a** 主播，**I want** 在浏览器页面里直接调字号、颜色、位置，**so that** 不用改代码重启。

## Functional Requirements

1. 识别结果默认做繁转简（可关闭）。
2. 支持黑名单过滤，命中则不显示该段字幕。
3. 支持 `initial_prompt`（和可选 hotwords）配置。
4. 提供 `/settings` 页面或主页面内嵌设置面板，可实时修改：
   - 字号
   - 文字颜色
   - 描边颜色/粗细
   - 底部边距
   - 最大显示行数
5. 设置通过 localStorage 持久化，刷新后保留。
6. 设置变更立即作用于当前字幕显示（无需重启识别服务）。

## Acceptance Criteria

- 给定繁体输出，最终显示为简体。
- 给定含「谢谢观看」的识别结果，页面不显示。
- 配置 `INITIAL_PROMPT` 后，识别行为受其影响（人工观察即可）。
- 打开设置面板修改字号，字幕立即变大/变小，刷新浏览器后仍保持。
- 原有 partial / final / fade 行为不回归。

## Non-functional

- 不增加明显识别延迟
- 设置面板不遮挡字幕区域（可折叠）
- 保持单文件可运行的风格（尽量少依赖）

## Out of Scope

- 云端翻译
- 多语言切换 UI
- 账号/云同步设置

## Success Metrics

- 幻听词出现率明显下降
- 主播能在 30 秒内完成一次样式调整并看到效果
